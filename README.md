# Pygame Boilerplate

A minimal Pygame template with a game loop, event handling, update logic, and drawing setup.

## Run it

1. Create a virtual environment if you want one.
2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Start the game:

   ```bash
   python main.py
   ```

Press `Esc` or close the window to exit.
